# NYC Airbnb Business Analysis
NYC Airbnb Business Analysis using Python and Power BI to analyze listing prices, room types, availability, reviews, and location-based trends.
## Project Overview
This project analyzes Airbnb listings in New York City to understand listing prices, room types, availability, reviews, and other business-related patterns.
## Objective
- Analyze Airbnb listing prices.
- Examine different room types.
- Analyze listing availability.
- Explore review patterns.
- Understand differences across listing characteristics and locations.
- Present findings through an interactive Power BI dashboard.
  ## Tools & Technologies
  - Python
  - Pandas
  - Numpy
  - Matplotlib
  - Seaborn
  - Jupyter Notebook
  - Power BI
  - Github
    ## Data Preparation & Analysis
    The Airbnb dataset was cleaned and analyzed using python in Jupyter Notebook. Relevant listing, pricing, room type, availability, and review fields were reviewed before visualization.
    ## Power BI Dashboard
  An interactive Power BI dashboard was created to analyze NYC Airbnb listing characteristics and business-related metrics.
  The dashboard includes analysis of:
  - Total listings
  - Average price
  - Average availability
  - Average reviews
  - Room types
  - Listing characteristics
  - Location-related patterns.
    ## Key Business Insights
    - listing prices vary across different room types and listing characteristics.
    - Room type distribution provides insight into the composition of Airbnb listings.
    - Availability can vary across listings.
    - Review patterns provide additional context for understanding listing activity.
    - The dashboard provides a consolidated view of NYC Airbnb listing characteristics.
